# Requestify

Requestify is a web application that allows users to search for Spotify tracks and request their favorites. All requested tracks are collected into a playlist, which can be moderated to curate the final playing queue.

## Features

- **Spotify Track Search:** Find any song available on Spotify.
- **Track Requests:** Users can request tracks to be added to a shared playlist.
- **Playlist Moderation:** Moderators can review requests and select tracks for the final queue.
- **Curated Playing Queue:** Only approved tracks make it to the final playlist for playback.

## Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/requestify.git
    cd requestify
    ```

2. **Install dependencies:**
    ```bash
    npm install
    ```

3. **Configure Spotify API credentials:**
    - Create a `.env` file with your Spotify API keys.

4. **Run the application:**
    ```bash
    npm start
    ```

## Usage

- Search for tracks using the search bar.
- Request tracks to add them to the playlist.
- Moderators can approve or reject requests.
- The curated playlist is updated in real-time.
